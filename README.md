# Urbanix

Tienda en línea migrada a React + Vite (frontend) con API Node.js, Express y MongoDB (backend).

## Requisitos
- Node.js
- MongoDB local

## Instalación
```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

## Variables de entorno
- `backend/.env` (no subir a Git). Ver `backend/.env.example`
- `frontend/.env` (no subir a Git). Ver `frontend/.env.example`

## Ejecutar
Abrir dos terminales:

```bash
# Terminal 1 - Backend
cd backend
npm run dev
```

```bash
# Terminal 2 - Frontend
cd frontend
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:3000
